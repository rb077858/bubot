# הבובות של ציבי

גלריית בובות סרוגות. פותחים את `index.html` בדפדפן.

## איך עורכים

כל התוכן נמצא בקובץ **`dolls.js`**:

- **`whatsappNumber`**: מספר הוואטסאפ לכפתורי "צור קשר" (בפורמט בינלאומי: `0541234567` נכתב `972541234567`).
- **`SITE`**: כותרת, תת-כותרת, טקסט פתיחה והודעת הוואטסאפ.
- **`DOLLS`**: רשימת הבובות. לכל בובה יש `name`, `image` ו-`description`.

להוספת בובה: שמים תמונה בתיקייה `images/` (עדיף עם רקע שקוף) ומוסיפים בלוק חדש לרשימה `DOLLS`.
